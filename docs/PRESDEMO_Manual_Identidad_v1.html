Sección 00

Propósito de este documento

Este manual registra el estado provisional de la identidad visual de Sendler Group. Su función es documentar los assets disponibles, establecer reglas de uso de color y terminología, y servir de referencia hasta que se defina la identidad de marca definitiva.

⚠️ Aviso importante — Versión provisional

Todos los logos incluidos en este documento son provisionales y serán reemplazados cuando se complete el proceso de definición de identidad de marca. Este manual documenta el estado actual (Mayo 2026) para uso interno y de referencia. No utilizar estos logos en materiales de comunicación definitivos sin validación previa.

Sección 05

Terminología de marca

Usar siempre los términos correctos. Nunca reemplazarlos por sinónimos, incluso en comunicaciones informales o código.

✓ Asistente Integral
cuidador/a · empleado/a · trabajador/a
✓ Familia
cliente · usuario
✓ Paciente
adulto mayor (excepto contexto clínico)
✓ Guardia
turno · jornada · servicio
✓ Proceso de Incorporación de Asistentes (uso interno — Panel y referencia general al concepto; nunca en sitio público ni redes)
"Filtro Sendler" (término retirado 2026-07-10, no usar ni siquiera internamente) · proceso de selección · verificación · "pipeline"
✓ Certificado Sendler
certificado · diploma · título
✓ Reporte diario
informe · planilla · parte
✓ Coordinador
supervisor · jefe · encargado
